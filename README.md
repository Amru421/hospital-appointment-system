# Hospital Appointment Management System

## Project Overview
The Hospital Appointment Management System is a web-based application designed to simplify the process of booking and managing hospital appointments. It helps patients connect with doctors, schedule appointments, and manage their booking details easily.

## Objectives
- Make hospital appointment booking easier.
- Reduce manual appointment scheduling.
- Help patients find available doctors.
- Allow doctors to manage appointments.
- Improve hospital appointment management.

## Key Features
1. Patient Registration and Login
2. Doctor Login
3. Doctor Profile Management
4. Appointment Booking
5. Date and Time Selection
6. Patient Dashboard
7. Doctor Dashboard
8. Appointment Status Tracking
9. Appointment Cancellation
10. Admin Dashboard

## Modules
- **Patient Module:** Registration, login, and appointment booking.
- **Doctor Module:** View and manage patient appointments.
- **Admin Module:** Manage doctors, patients, and appointments.
